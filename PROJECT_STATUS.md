# Project status

Ametherian is currently in the **proposal and specification stage**.

This repository describes an intended ecosystem and a way to develop it. It does not represent released packages or completed security functionality.

| Area | Current status | What would establish progress |
|---|---|---|
| Project vision | Drafted | Maintainer review and community feedback |
| Package taxonomy | Proposed | Architecture decisions and package ownership |
| HTTP and transport research | Initial direction documented | Feature-level specifications and runtime tests |
| Security model | Proposed requirements | Threat model, reviewed controls, adversarial tests |
| Vulnerability intelligence | Proposed workflow | Working ingestion, provenance, triage, and regression pipeline |
| Package implementations | Not represented as complete here | Published source, tests, changelog, and package release |
| Security audit | Not performed | Independent review with scope and report |

Do not describe Ametherian as production-ready, audited, secure against all vulnerabilities, faster than competitors, or a drop-in replacement until evidence supports the specific statement.
