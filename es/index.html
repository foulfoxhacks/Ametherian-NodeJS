Ecosistema independiente para Node.js

Un nuevo tipo de ecosistema de bibliotecas para Node.

Ametherian es una familia de bibliotecas modulares de JavaScript y TypeScript bajo el ámbito @foulfoxhacks de npm. Diez paquetes existen como versiones preliminares probadas: paquetes enfocados, contratos compartidos y seguridad considerada desde la primera decisión de diseño.

Resumen

Un ecosistema. Herramientas que se adoptan por separado.

Quienes desarrollan con Node.js montan redes, validación, caché, concurrencia, observabilidad e infraestructura de aplicaciones a partir de muchos paquetes. Ametherian investiga dónde unos contratos coherentes y unos límites de paquete bien definidos pueden hacer ese trabajo más fácil de entender y mantener.

Cada paquete tiene un propósito claro, un comportamiento documentado, límites explícitos y la libertad de adoptarse por sí solo. La ambición va más allá de sustituir un único cliente HTTP.

Arquitectura

Construido sobre las primitivas de Node.js.

Ametherian se apoya en las API consolidadas del runtime en lugar de inventar una forma paralela de escribir JavaScript. Las afirmaciones de compatibilidad y rendimiento necesitarán pruebas reproducibles antes de publicarse.

Leer la dirección de arquitectura →
server.mjs 
import { createServer } from 'node:http';

const server = createServer((request, response) => {
  response.writeHead(200, { 'content-type': 'text/plain' });
  response.end('Hello from Node.js\n');
});

server.listen(3000, () => {
  console.log('Listening on http://localhost:3000');
});

Principios rectores

Pautas de desarrollo.

Estos principios son requisitos para cada paquete; las pruebas, los modelos de amenazas y la revisión los verifican. Se aplican a los límites de los paquetes, la documentación, las pruebas y la revisión.

Paquetes enfocados

Un paquete debe tener una responsabilidad comprensible y seguir siendo útil sin módulos ajenos.

Comportamiento explícito

Los requisitos del runtime, los efectos secundarios, los límites, los modos de fallo y el manejo de datos deben documentarse en lugar de ocultarse.

Interoperabilidad

Aprender de bibliotecas consolidadas, interoperar donde sea útil y evitar reinventar sin necesidad.

Pruebas antes que afirmaciones

Las afirmaciones de compatibilidad, rendimiento, seguridad y fiabilidad necesitan pruebas reproducibles o una etiqueta clara como objetivos.

Seguridad desde el diseño

Los modelos de amenazas, los recursos acotados y los valores predeterminados seguros forman parte del diseño, no de una lista de comprobación posterior.

Cambios revisados por personas

Las correcciones sensibles para la seguridad y las afirmaciones públicas requieren la revisión de personas responsables del resultado.

Preguntas frecuentes

Sobre el proyecto.

Respuestas directas sobre estado, afiliación, runtime, licencia y contribución.

¿Está publicado Ametherian?

Todavía no en npm. Diez paquetes en vista previa son públicos en el repositorio con sus pruebas, y cada build que pasa la CI se publica como versión preliminar numerada en GitHub Releases. La publicación en npm espera a un proceso de publicación acordado.

¿Está Ametherian afiliado a Node.js o a la OpenJS Foundation?

No. Ametherian es un proyecto independiente de FoulFoxHacks. No está afiliado, respaldado ni es una continuación oficial de Node.js, la OpenJS Foundation, Axios, Undici ni ningún otro proyecto mencionado. Node.js es una marca registrada de la OpenJS Foundation.

¿Está Ametherian listo para producción o auditado?

No. Diez paquetes existen como versiones preliminares probadas, pero ninguno está publicado en npm y no se ha realizado ninguna auditoría de seguridad independiente. El enfoque de seguridad y el modelo de vulnerabilidades describen cómo se modelan las amenazas y se prueba el código; no garantizan que sea seguro.

¿Para qué runtime está pensado Ametherian?

Node.js 22, 24 y 26, cada uno en su versión de seguridad más reciente. Los paquetes son módulos ES con declaraciones de TypeScript. Node.js 20 no es compatible: llegó al final de su vida útil en abril de 2026.

¿Qué licencia usará el proyecto?

La Licencia Apache 2.0. Es una licencia permisiva con una concesión explícita de patentes. El texto completo está en el estado de la licencia y en cada paquete.

¿Puedo contribuir?

Se agradecen los comentarios tempranos sobre el alcance, los límites de los paquetes, los requisitos de seguridad, la compatibilidad del runtime y la experiencia de desarrollo. La guía de contribución explica lo que se espera. Los detalles sensibles para la seguridad no deben publicarse; sigue la política de seguridad.

¿Hay un calendario de publicación?

No hay fechas. Cada build de la rama principal que pasa la CI se publica como versión preliminar numerada en GitHub Releases y aparece en el registro de cambios. La publicación en npm espera a un proceso de publicación acordado.

¿Sustituye Ametherian a Axios o Undici?

No. El cliente HTTP y fetch() de Ametherian son código propio, comprobado frente a cada aviso de seguridad publicado de Axios y Undici. No es un sustituto directo y no hace afirmaciones de compatibilidad ni de rendimiento sin pruebas reproducibles.
