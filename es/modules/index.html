Vulnerability model#

Every published advisory for undici and axios is mapped: 111 in total, 64 prevented, each with a regression test named after the advisory, and 47 not applicable, each with the reason recorded. A daily workflow checks OSV, the GitHub Advisory Database and NIST NVD for new ones.

Read the vulnerability model ↗

Supported runtimes#

The minimum for each line is its latest Node.js security release. The advisory watch fails when a newer security release ships or a line reaches end of life.

  • Node.js 22: 22.23.5 or later
  • Node.js 24: 24.22.3 or later
  • Node.js 26: 26.13.1 or later

Node.js 20 is not supported: it reached end of life on 30 April 2026.

What preview means#

  • Code, tests, type declarations and threat models are public in the repository.
  • Nothing is published to npm until a license is chosen and a release process is agreed.
  • No independent security audit has been performed.
