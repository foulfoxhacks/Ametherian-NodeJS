Modelo de vulnerabilidades#

Cada aviso publicado para undici e axios está catalogado: 111 no total, 64 prevenidos, cada um com um teste de regressão que leva o nome do aviso, e 47 não aplicáveis, cada um com o motivo registrado. Um fluxo de trabalho diário consulta OSV, o GitHub Advisory Database e o NIST NVD em busca de avisos novos.

Ler o modelo de vulnerabilidades ↗

Runtimes suportados#

O mínimo de cada linha é a sua versão de segurança mais recente do Node.js. O monitoramento de avisos falha quando sai uma versão de segurança mais nova ou quando uma linha chega ao fim da vida útil.

  • Node.js 22: 22.23.5 ou posterior
  • Node.js 24: 24.22.3 ou posterior
  • Node.js 26: 26.13.1 ou posterior

O Node.js 20 não é suportado: chegou ao fim da vida útil em 30 de abril de 2026.

O que significa prévia#

  • Código, testes, declarações de tipos e modelos de ameaças são públicos no repositório.
  • Nada é publicado no npm até que uma licença seja escolhida e um processo de lançamento seja acordado.
  • Nenhuma auditoria de segurança independente foi realizada.

Projeto independente. O Ametherian não é afiliado nem endossado pelo Node.js, pela OpenJS Foundation, pelo Axios, pelo Undici ou por qualquer outro projeto mencionado. Node.js é uma marca registrada da OpenJS Foundation.
