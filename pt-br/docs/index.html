Como ler a documentação#

  • Planejar não é implementar. Uma capacidade, um nome de pacote ou um controle de segurança descrito é uma direção até que existam código, testes, documentação e um lançamento.
  • Afirmações precisam de evidências. Afirmações de compatibilidade, desempenho, confiabilidade e segurança devem ser reproduzíveis ou explicitamente rotuladas como objetivos.
  • Datas não são promessas. O roteiro é feito em etapas. Compromissos de lançamento não são publicados até que escopo, responsabilidade e capacidade estejam definidos.
  • Nomes de terceiros indicam contexto. Axios, Undici, Node.js e OpenJS são mencionados para descrever o ecossistema e suas restrições, não para sugerir afiliação ou endosso.

Registros do projeto#

Estes documentos do repositório são as fontes em texto puro do site. Eles são úteis para revisar o status.

Projeto independente. O Ametherian não é afiliado nem endossado pelo Node.js, pela OpenJS Foundation, pelo Axios, pelo Undici ou por qualquer outro projeto mencionado. Node.js é uma marca registrada da OpenJS Foundation.
