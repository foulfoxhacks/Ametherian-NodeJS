Ecossistema independente para Node.js

Um novo tipo de ecossistema de bibliotecas para Node.

Ametherian é uma família de bibliotecas modulares de JavaScript e TypeScript sob o escopo @foulfoxhacks do npm. Seus pacotes existem como prévias testadas: pacotes focados, contratos compartilhados e segurança considerada desde a primeira decisão de design.

Visão geral

Um ecossistema. Ferramentas adotáveis de forma independente.

Quem desenvolve com Node.js monta redes, validação, cache, concorrência, observabilidade e infraestrutura de aplicações a partir de muitos pacotes. O Ametherian investiga onde contratos consistentes e limites de pacote bem definidos podem tornar esse trabalho mais fácil de entender e manter.

Cada pacote tem um propósito claro, comportamento documentado, limites explícitos e a liberdade de ser adotado sozinho. A ambição vai além de substituir um único cliente HTTP.

Arquitetura

Construído sobre as primitivas do Node.js.

O Ametherian se apoia nas APIs consolidadas do runtime em vez de inventar uma forma paralela de escrever JavaScript. Afirmações de compatibilidade e desempenho vão precisar de evidências reproduzíveis antes de serem publicadas.

Ler a direção de arquitetura →
server.mjs 
import { createServer } from 'node:http';

const server = createServer((request, response) => {
  response.writeHead(200, { 'content-type': 'text/plain' });
  response.end('Hello from Node.js\n');
});

server.listen(3000, () => {
  console.log('Listening on http://localhost:3000');
});

Princípios norteadores

Diretrizes de desenvolvimento.

Estes princípios são requisitos para cada pacote; testes, modelos de ameaças e revisão os verificam. Eles se aplicam aos limites dos pacotes, à documentação, aos testes e à revisão.

Pacotes focados

Um pacote deve ter uma responsabilidade compreensível e continuar útil sem módulos não relacionados.

Comportamento explícito

Requisitos de runtime, efeitos colaterais, limites, modos de falha e tratamento de dados devem ser documentados em vez de escondidos.

Interoperabilidade

Aprender com bibliotecas consolidadas, interoperar onde for útil e evitar reinvenções desnecessárias.

Evidências acima de afirmações

Afirmações de compatibilidade, desempenho, segurança e confiabilidade precisam de testes reproduzíveis ou de um rótulo claro de objetivo.

Segurança desde o design

Modelos de ameaças, recursos limitados e padrões seguros fazem parte do design, não de uma lista de verificação posterior.

Mudanças revisadas por pessoas

Correções sensíveis à segurança e afirmações públicas exigem revisão de pessoas responsáveis pelo resultado.

Perguntas frequentes

Sobre o projeto.

Respostas diretas sobre status, afiliação, runtime, licenciamento e contribuição.

O Ametherian já foi lançado?

Ainda não no npm. Os pacotes em prévia são públicos no repositório com testes, e cada build aprovado na CI é publicado como prévia numerada no GitHub Releases. A publicação no npm aguarda um processo de lançamento acordado.

O Ametherian é afiliado ao Node.js ou à OpenJS Foundation?

Não. O Ametherian é um projeto independente da FoulFoxHacks. Não é afiliado, endossado nem uma continuação oficial do Node.js, da OpenJS Foundation, do Axios, do Undici ou de qualquer outro projeto mencionado. Node.js é uma marca registrada da OpenJS Foundation.

O Ametherian está pronto para produção ou foi auditado?

Não. Os pacotes existem como prévias testadas, mas nenhum está publicado no npm e nenhuma auditoria de segurança independente foi realizada. A abordagem de segurança e o modelo de vulnerabilidades descrevem como o código passa por modelagem de ameaças e testes; não são uma garantia de que ele seja seguro.

Qual runtime o Ametherian suporta?

Node.js 22, 24 e 26, cada um na sua versão de segurança mais recente. Os pacotes são módulos ES com declarações de TypeScript. O Node.js 20 não é suportado: chegou ao fim da vida útil em abril de 2026.

Qual licença o projeto vai usar?

A Licença Apache 2.0. É uma licença permissiva com uma concessão explícita de patentes. O texto completo está no status da licença e em cada pacote.

Posso contribuir?

Comentários iniciais sobre escopo, limites dos pacotes, requisitos de segurança, compatibilidade de runtime e experiência de desenvolvimento são bem-vindos. O guia de contribuição explica as expectativas. Detalhes sensíveis à segurança não devem ser publicados; siga a política de segurança.

Existe um cronograma de lançamento?

Não há datas. Cada build da branch principal aprovado na CI é publicado como prévia numerada no GitHub Releases e listado no registro de alterações. A publicação no npm aguarda um processo de lançamento acordado.

O Ametherian substitui o Axios ou o Undici?

Não. O cliente HTTP e o fetch() do Ametherian são código próprio, verificado contra cada aviso de segurança publicado do Axios e do Undici. Não é um substituto direto e não faz afirmações de compatibilidade ou desempenho sem evidências reproduzíveis.
