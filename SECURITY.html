Security policy

Reporting status and the intended security process.

Reviewed November 2026 · Source repository ↗

This policy applies to the planning repository and will apply to future implementation repositories.

Reporting a vulnerability#

Do not open a public issue for a security vulnerability. Report it privately to the maintainers. Security-sensitive details must not be posted publicly before coordinated disclosure.

Scope#

There are currently no released packages and no security-audited guarantees. If a vulnerability is found in the site infrastructure or repository configuration, it should be reported following this policy.

Intended process#

  • Acknowledge receipt of the report.
  • Investigate and confirm the issue.
  • Develop and test a fix.
  • Coordinate disclosure and credit.
