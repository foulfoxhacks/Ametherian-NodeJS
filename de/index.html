Unabhängiges Node.js-Ökosystem

Eine neue Art von Bibliotheks-Ökosystem für Node.

Ametherian ist eine Familie modularer JavaScript- und TypeScript-Bibliotheken im npm-Scope @foulfoxhacks . Die Pakete existieren als getestete Vorschauversionen: fokussierte Pakete, gemeinsame Verträge und Sicherheit ab der ersten Designentscheidung.

Überblick

Ein Ökosystem. Unabhängig einsetzbare Werkzeuge.

Node.js-Entwickler setzen Netzwerk, Validierung, Caching, Nebenläufigkeit, Observability und Anwendungsinfrastruktur aus vielen Paketen zusammen. Ametherian untersucht, wo einheitliche Verträge und klar definierte Paketgrenzen diese Arbeit verständlicher und leichter wartbar machen können.

Jedes Paket hat einen klaren Zweck, dokumentiertes Verhalten, ausdrückliche Grenzen und kann für sich allein eingesetzt werden. Das Ziel reicht weiter, als nur einen einzelnen HTTP-Client zu ersetzen.

Architektur

Aufgebaut auf Node.js-Grundbausteinen.

Ametherian baut auf den etablierten APIs der Laufzeit auf, statt eine parallele Art zu erfinden, JavaScript zu schreiben. Aussagen zu Kompatibilität und Leistung brauchen reproduzierbare Belege, bevor sie veröffentlicht werden.

import { createServer } from 'node:http';

const server = createServer((request, response) => {
  response.writeHead(200, { 'content-type': 'text/plain' });
  response.end('Hello from Node.js\n');
});

server.listen(3000, () => {
  console.log('Listening on http://localhost:3000');

Leitprinzipien

Entwicklungsrichtlinien.

Diese Prinzipien sind Anforderungen an jedes Paket; Tests, Bedrohungsmodelle und Reviews überprüfen sie. Sie gelten für Paketgrenzen, Dokumentation, Tests und Reviews.

Fokussierte Pakete

Ein Paket sollte eine verständliche Aufgabe haben und ohne fremde Module nützlich bleiben.

Ausdrückliches Verhalten

Laufzeitanforderungen, Nebenwirkungen, Grenzen, Fehlerfälle und Datenverarbeitung sollten dokumentiert statt versteckt werden.

Interoperabilität

Von etablierten Bibliotheken lernen, wo sinnvoll mit ihnen zusammenarbeiten und unnötiges Neuerfinden vermeiden.

Belege statt Behauptungen

Aussagen zu Kompatibilität, Leistung, Sicherheit und Zuverlässigkeit brauchen reproduzierbare Tests oder eine klare Kennzeichnung als Ziel.

Sicherheit durch Design

Bedrohungsmodelle, begrenzte Ressourcen und sichere Standardwerte gehören ins Design, nicht auf eine spätere Checkliste.

Von Menschen geprüfte Änderungen

Sicherheitsrelevante Korrekturen und öffentliche Aussagen müssen von Personen geprüft werden, die für das Ergebnis verantwortlich sind.

FAQ

Über das Projekt.

Direkte Antworten zu Status, Zugehörigkeit, Laufzeit, Lizenz und Mitwirkung.

Ist Ametherian veröffentlicht?

Noch nicht auf npm. Die Vorschaupakete sind mit Tests öffentlich im Repository, und jeder Build, der die CI besteht, wird als nummerierte Vorschau auf GitHub Releases veröffentlicht. Die Veröffentlichung auf npm wartet auf einen abgestimmten Release-Prozess.

Ist Ametherian mit Node.js oder der OpenJS Foundation verbunden?

Nein. Ametherian ist ein unabhängiges Projekt von FoulFoxHacks. Es ist weder mit Node.js, der OpenJS Foundation, Axios, Undici noch einem anderen genannten Projekt verbunden, von ihnen unterstützt oder deren offizielle Fortsetzung. Node.js ist eine Marke der OpenJS Foundation.

Ist Ametherian produktionsreif oder auditiert?

Nein. Die Pakete existieren als getestete Vorschauversionen, aber keines ist auf npm veröffentlicht, und es wurde kein unabhängiges Sicherheitsaudit durchgeführt. Der Sicherheitsansatz und das Schwachstellenmodell beschreiben, wie der Code bedrohungsmodelliert und getestet wird; sie sind keine Garantie, dass er sicher ist.

Für welche Laufzeit ist Ametherian gedacht?

Node.js 22, 24 und 26, jeweils in der neuesten Sicherheitsversion. Die Pakete sind ES-Module mit TypeScript-Deklarationen. Node.js 20 wird nicht unterstützt: Es hat im April 2026 das Ende seiner Lebensdauer erreicht.

Welche Lizenz wird das Projekt verwenden?

Die Apache License 2.0. Sie ist eine freizügige Lizenz mit ausdrücklicher Patentgewährung. Der vollständige Text steht im Lizenzstatus und in jedem Paket.

Kann ich mitmachen?

Frühes Feedback zu Umfang, Paketgrenzen, Sicherheitsanforderungen, Laufzeitkompatibilität und Entwicklererfahrung ist willkommen. Der Leitfaden zur Mitwirkung erklärt die Erwartungen. Sicherheitsrelevante Details dürfen nicht öffentlich gepostet werden; folge der Sicherheitsrichtlinie.

Gibt es einen Zeitplan für Releases?

Es gibt keine Termine. Jeder Build des Hauptzweigs, der die CI besteht, wird als nummerierte Vorschau auf GitHub Releases veröffentlicht und im Änderungsprotokollaufgeführt. Die Veröffentlichung auf npm wartet auf einen abgestimmten Release-Prozess.

Ersetzt Ametherian Axios oder Undici?

Nein. Der HTTP-Client und fetch() von Ametherian sind eigener Code, geprüft gegen jede veröffentlichte Sicherheitsmeldung zu Axios und Undici. Es ist kein direkter Ersatz und macht ohne reproduzierbare Belege keine Aussagen zu Kompatibilität oder Leistung.
