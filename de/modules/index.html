Schwachstellenmodell#

Jede veröffentlichte Sicherheitsmeldung zu undici und axios ist erfasst: 111 insgesamt, 64 verhindert, jeweils mit einem nach der Meldung benannten Regressionstest, und 47 nicht zutreffend, jeweils mit dokumentierter Begründung. Ein täglicher Workflow prüft OSV, die GitHub Advisory Database und NIST NVD auf neue Meldungen.

Das Schwachstellenmodell lesen ↗

Unterstützte Laufzeiten#

Das Minimum jeder Linie ist ihre neueste Node.js-Sicherheitsversion. Die Überwachung schlägt fehl, wenn eine neuere Sicherheitsversion erscheint oder eine Linie das Ende ihrer Lebensdauer erreicht.

  • Node.js 22: 22.23.5 oder neuer
  • Node.js 24: 24.22.3 oder neuer
  • Node.js 26: 26.13.1 oder neuer

Node.js 20 wird nicht unterstützt: Es hat am 30. April 2026 das Ende seiner Lebensdauer erreicht.

Was Vorschau bedeutet#

  • Code, Tests, Typdeklarationen und Bedrohungsmodelle sind öffentlich im Repository.
  • Nichts wird auf npm veröffentlicht, bevor eine Lizenz gewählt und ein Release-Prozess vereinbart ist.
  • Es wurde kein unabhängiges Sicherheitsaudit durchgeführt.

Unabhängiges Projekt. Ametherian ist weder mit Node.js, der OpenJS Foundation, Axios, Undici noch einem anderen genannten Projekt verbunden oder von ihnen unterstützt. Node.js ist eine Marke der OpenJS Foundation.
