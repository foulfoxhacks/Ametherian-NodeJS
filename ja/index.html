Node.js のための独立したエコシステム

新しいタイプの Node ライブラリ エコシステム。

Ametherian は、npm スコープ @foulfoxhacks の下にある JavaScript と TypeScript のモジュール式ライブラリ群です。10 個のパッケージがテスト済みのプレビュー版として存在します。目的を絞ったパッケージ、共通の契約、そして最初の設計判断から考慮されたセキュリティが特長です。

概要

ひとつのエコシステム。個別に導入できるツール。

Node.js の開発者は、ネットワーク、バリデーション、キャッシュ、並行処理、可観測性、アプリケーション基盤を多くのパッケージから組み立てています。Ametherian は、一貫した契約と明確に定義されたパッケージ境界によって、その作業をより理解しやすく保守しやすくできる場所を探っています。

各パッケージには明確な目的、文書化された動作、明示された制限があり、単体で導入できます。目指すのは、単一の HTTP クライアントを置き換えること以上のものです。

アーキテクチャ

Node.js のプリミティブの上に構築。

Ametherian は、JavaScript の書き方を別に発明するのではなく、ランタイムの確立された API の上に構築しています。互換性や性能に関する主張は、公開する前に再現可能な根拠が必要です。

アーキテクチャの方針を読む →
server.mjs 
import { createServer } from 'node:http';

const server = createServer((request, response) => {
  response.writeHead(200, { 'content-type': 'text/plain' });
  response.end('Hello from Node.js\n');
});

server.listen(3000, () => {
  console.log('Listening on http://localhost:3000');
});

よくある質問

プロジェクトについて。

状況、所属関係、ランタイム、ライセンス、コントリビューションについての率直な回答。

Ametherian はリリースされていますか？

npm にはまだ公開されていません。 10 個のプレビューパッケージ はテスト付きでリポジトリに公開されており、CI に合格したビルドはすべて番号付きのプレビューとして GitHub Releases に公開されます。npm での公開は、合意されたリリース手順を待っています。

Ametherian は Node.js や OpenJS Foundation と関係がありますか？

いいえ。Ametherian は FoulFoxHacks による独立したプロジェクトです。Node.js、OpenJS Foundation、Axios、Undici、その他言及しているいかなるプロジェクトとも提携しておらず、支持も受けておらず、公式な後継でもありません。Node.js は OpenJS Foundation の商標です。

Ametherian は本番環境で使えますか？監査は受けていますか？

いいえ。10 個のパッケージがテスト済みのプレビュー版として存在しますが、npm には公開されておらず、独立したセキュリティ監査も行われていません。 セキュリティ方針 と脆弱性モデルは、コードの脅威モデリングとテストの方法を説明するものであり、安全性を保証するものではありません。

Ametherian はどのランタイムを対象にしていますか？

Node.js 22、24、26 で、それぞれ最新のセキュリティリリースが対象です。パッケージは TypeScript の型宣言付きの ES モジュールです。Node.js 20 は 2026 年 4 月にサポート終了を迎えたため、対象外です。

プロジェクトはどのライセンスを使いますか？

Apache License 2.0 です。特許の明示的な許諾を含む寛容なライセンスです。全文は ライセンスの状況 と各パッケージにあります。

コントリビュートできますか？

対象範囲、パッケージ境界、セキュリティ要件、ランタイムの互換性、開発者体験についての早い段階のフィードバックを歓迎します。期待事項は コントリビューションガイド にまとめています。セキュリティに関わる詳細は公開せず、次に従ってください： セキュリティポリシー.

リリースのスケジュールはありますか？

日付はありません。メインブランチのビルドのうち CI に合格したものはすべて、番号付きのプレビュービルドとして GitHub Releases に公開され、 変更履歴に記載されます。npm での公開は、合意されたリリース手順を待っています。

Ametherian は Axios や Undici の代わりになりますか？

いいえ。Ametherian の HTTP クライアントと fetch() は独自のコードで、Axios と Undici について公開されたすべてのセキュリティアドバイザリと照合して確認しています。そのまま置き換えられるものではなく、再現可能な根拠なしに互換性や性能を主張することもありません。
