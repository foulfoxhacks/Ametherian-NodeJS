パッケージマップ

5 つの領域と、それぞれのプレビューパッケージ。

2026 年 11 月に確認 · ソースリポジトリ ↗

パッケージマップでは Ametherian を 5 つの領域に分けています。どの領域にも、テスト、型宣言、脅威モデルを備えたプレビューパッケージがあります。詳しくは モジュール をご覧ください。最初の安定版リリースまでは、パッケージの API が変わる可能性があります。

ネットワークとプロトコル#

HTTP クライアント、トランスポート、コネクションプール、プロキシ、ストリーミング、リトライ、期限、キャンセル。

プレビューパッケージ： ametherian-http, ametherian-guard, ametherian-youtube-chat.

データとシリアライズ#

バリデーション、スキーマ、パース、シリアライズ、変換、構造化データ、信頼できない入力の安全な扱い。

プレビューパッケージ： ametherian-schema, ametherian-frontmatter.

アプリケーション基盤#

キャッシュ、キュー、並行処理、レート制限、設定、ライフサイクル管理、レジリエンス。

プレビューパッケージ： ametherian-core, ametherian-cache, ametherian-resilience.

セキュリティエンジニアリング#

セキュリティポリシーの補助、安全な設定、依存関係のレビュー、テスト用データ、回帰テスト用ツール。

プレビューパッケージ： ametherian-security.

可観測性と開発者体験#

ロギング、診断、メトリクス、トレーシング、型付きエラー、テストユーティリティ、ファジング補助、ドキュメントツール。

プレビューパッケージ： ametherian-observability, ametherian-testing.

独立したプロジェクトです。 Ametherian は Node.js、OpenJS Foundation、Axios、Undici、その他言及しているいかなるプロジェクトとも提携しておらず、支持も受けていません。Node.js は OpenJS Foundation の商標です。
