Модель уязвимостей#

Каждый опубликованный бюллетень для undici и axios учтён: 111 всего, 64 предотвращено, у каждого есть регрессионный тест с именем бюллетеня, и 47 неприменимо, для каждого записана причина. Ежедневный процесс проверяет OSV, GitHub Advisory Database и NIST NVD на наличие новых бюллетеней.

Поддерживаемые среды выполнения#

Минимальная версия для каждой ветки — её последний выпуск Node.js с исправлениями безопасности. Мониторинг завершается ошибкой, когда выходит более новый выпуск с исправлениями безопасности или ветка достигает конца срока поддержки.

  • Node.js 22: 22.23.5 или новее
  • Node.js 24: 24.22.3 или новее
  • Node.js 26: 26.13.1 или новее

Node.js 20 не поддерживается: срок его поддержки закончился 30 апреля 2026 года.

Что означает предварительная версия#

  • Код, тесты, объявления типов и модели угроз открыты в репозитории.
  • В npm ничего не публикуется, пока не выбрана лицензия и не согласован процесс выпуска.
  • Независимый аудит безопасности не проводился.

Независимый проект. Ametherian не связан с Node.js, OpenJS Foundation, Axios, Undici или любым другим упомянутым проектом и не одобрен ими. Node.js — товарный знак OpenJS Foundation.
