Независимая экосистема для Node.js

Новый тип экосистемы библиотек для Node.

Ametherian — семейство модульных библиотек на JavaScript и TypeScript в пространстве имён npm @foulfoxhacks . Десять пакетов существуют в виде протестированных предварительных версий: узконаправленные пакеты, общие контракты и безопасность, учтённая с первого проектного решения.

Обзор

Одна экосистема. Инструменты, которые можно внедрять по отдельности.

Разработчики на Node.js собирают сетевое взаимодействие, валидацию, кеширование, параллелизм, наблюдаемость и инфраструктуру приложений из множества пакетов. Ametherian исследует, где согласованные контракты и чётко определённые границы пакетов могут сделать эту работу понятнее и проще в сопровождении.

У каждого пакета ясное назначение, задокументированное поведение, явные ограничения и возможность использовать его отдельно. Цель шире, чем замена одного HTTP-клиента.

Архитектура

Построено на примитивах Node.js.

Ametherian опирается на устоявшиеся API среды выполнения, а не изобретает параллельный способ писать на JavaScript. Заявления о совместимости и производительности потребуют воспроизводимых доказательств, прежде чем будут опубликованы.

Читать о направлении архитектуры →
server.mjs 
import { createServer } from 'node:http';

const server = createServer((request, response) => {
  response.writeHead(200, { 'content-type': 'text/plain' });
  response.end('Hello from Node.js\n');
});

server.listen(3000, () => {
  console.log('Listening on http://localhost:3000');
});

Руководящие принципы

Правила разработки.

Эти принципы — требования к каждому пакету; их проверяют тесты, модели угроз и ревью. Они относятся к границам пакетов, документации, тестам и ревью.

Узконаправленные пакеты

У пакета должна быть одна понятная задача, и он должен оставаться полезным без посторонних модулей.

Явное поведение

Требования к среде выполнения, побочные эффекты, ограничения, режимы отказа и обработка данных должны быть задокументированы, а не скрыты.

Совместимость

Учиться у устоявшихся библиотек, взаимодействовать с ними там, где это полезно, и не изобретать заново без необходимости.

Доказательства важнее заявлений

Заявления о совместимости, производительности, безопасности и надёжности требуют воспроизводимых тестов или явной пометки «цель».

Безопасность с этапа проектирования

Модели угроз, ограниченные ресурсы и безопасные значения по умолчанию — часть проектирования, а не позднего чек-листа.

Изменения, проверенные людьми

Исправления, важные для безопасности, и публичные заявления должны проверять люди, отвечающие за результат.

Вопросы и ответы

О проекте.

Прямые ответы о статусе, связях, среде выполнения, лицензии и участии.

Ametherian уже выпущен?

В npm — ещё нет. Десять пакетов в предварительной версии открыты в репозитории вместе с тестами, а каждая сборка, прошедшая CI, публикуется как пронумерованная предварительная версия на GitHub Releases. Публикация в npm ждёт выбора лицензии и согласованного процесса выпуска.

Связан ли Ametherian с Node.js или OpenJS Foundation?

Нет. Ametherian — независимый проект FoulFoxHacks. Он не связан с Node.js, OpenJS Foundation, Axios, Undici или любым другим упомянутым проектом, не одобрен ими и не является их официальным продолжением. Node.js — товарный знак OpenJS Foundation.

Готов ли Ametherian к продакшену и проходил ли он аудит?

Нет. Десять пакетов существуют как протестированные предварительные версии, но ни один не опубликован в npm, и независимый аудит безопасности не проводился. Подход к безопасности и модель уязвимостей описывают, как для кода моделируются угрозы и как он тестируется; это не гарантия его безопасности.

Для какой среды выполнения предназначен Ametherian?

Node.js 22, 24 и 26, каждый в последнем выпуске с исправлениями безопасности. Пакеты — это ES-модули с объявлениями TypeScript. Node.js 20 не поддерживается: срок его поддержки закончился в апреле 2026 года.

Какую лицензию будет использовать проект?

Лицензия пока не выбрана. В разделе «Статус лицензии» сказано, что сопровождающие должны выбрать лицензию и определить правила участия и использования зависимостей до публикации кода. Не считайте, что этот репозиторий предоставляет лицензию.

Можно ли участвовать?

Мы рады ранним отзывам о рамках проекта, границах пакетов, требованиях безопасности, совместимости со средой выполнения и удобстве разработки. В руководстве для участников описаны ожидания. Сведения, важные для безопасности, нельзя публиковать открыто; следуйте политике безопасности.

Есть ли график выпусков?

Сроков нет. Каждая сборка основной ветки, прошедшая CI, публикуется как пронумерованная предварительная версия на GitHub Releases и указывается в журнале изменений. Публикация в npm ждёт выбора лицензии и согласованного процесса выпуска.

Заменяет ли Ametherian Axios или Undici?

Нет. HTTP-клиент и fetch() в Ametherian — собственный код, проверенный по каждому опубликованному бюллетеню безопасности Axios и Undici. Это не прямая замена, и без воспроизводимых доказательств проект не делает заявлений о совместимости или производительности.
