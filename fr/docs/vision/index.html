Vision du projet

Un écosystème cohérent de paquets ciblés, pas une dépendance surdimensionnée.

Relu en novembre 2026 · Dépôt de code ↗

Pourquoi un écosystème#

Node.js dispose d’un écosystème de paquets mature. Il connaît aussi des frictions récurrentes : paquets qui se recoupent, contrats incohérents, limites non documentées et niveau de sécurité variable selon les mainteneurs. Ametherian étudie si une famille cohérente de paquets ciblés peut réduire ces frictions sans imposer l’adoption d’une dépendance surdimensionnée.

Le but n’est pas un framework unique. Le but est un ensemble de modules qui partagent des conventions, documentent leur comportement et peuvent être adoptés séparément.

Ce qui est dans le périmètre#

La carte des paquets regroupe le travail en cinq domaines : réseau, données et sérialisation, infrastructure applicative, ingénierie de la sécurité et observabilité.

  • Des responsabilités ciblées. Un paquet doit faire une chose compréhensible et rester utile sans modules sans rapport.
  • Des limites explicites. Les exigences du runtime, les effets de bord, les modes de défaillance et les limites de ressources doivent être documentés plutôt que cachés.
  • Sécurité dès la conception. Les modèles de menaces et les valeurs par défaut sûres font partie de la conception, pas d’une liste de contrôle ultérieure.

Ce que le projet ne promet pas#

  • La prévention complète des vulnérabilités.
  • Une compatibilité universelle avec n’importe quelle application ou n’importe quel runtime.
  • Une sécurité automatique pour les applications qui utilisent ou configurent mal un paquet.
  • Le remplacement direct d’Axios, d’Undici ou de toute autre bibliothèque existante.

Projet indépendant. Ametherian n’est ni affilié ni soutenu par Node.js, l’OpenJS Foundation, Axios, Undici ou tout autre projet cité. Node.js est une marque de l’OpenJS Foundation.
