Modèle de vulnérabilités#

Chaque avis publié pour undici et axios est répertorié : 111 au total, 64 évités, chacun avec un test de régression qui porte le nom de l’avis, et 47 non applicables, chacun avec la raison consignée. Un workflow quotidien interroge OSV, la GitHub Advisory Database et NIST NVD pour détecter les nouveaux avis.

Runtimes pris en charge#

Le minimum de chaque branche est sa version de sécurité de Node.js la plus récente. La veille échoue lorsqu’une version de sécurité plus récente paraît ou qu’une branche atteint sa fin de vie.

  • Node.js 22: 22.23.5 ou ultérieure
  • Node.js 24: 24.22.3 ou ultérieure
  • Node.js 26: 26.13.1 ou ultérieure

Node.js 20 n’est pas pris en charge : il a atteint sa fin de vie le 30 avril 2026.

Ce que signifie préversion#

  • Le code, les tests, les déclarations de types et les modèles de menaces sont publics dans le dépôt.
  • Rien n’est publié sur npm tant qu’un processus de publication n’est pas convenu.
  • Aucun audit de sécurité indépendant n’a été réalisé.

Projet indépendant. Ametherian n’est ni affilié ni soutenu par Node.js, l’OpenJS Foundation, Axios, Undici ou tout autre projet cité. Node.js est une marque de l’OpenJS Foundation.
