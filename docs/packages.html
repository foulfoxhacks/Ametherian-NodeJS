Proposed package map

The following families are research areas, not released packages or a commitment that every candidate will ship.

Networking and protocols

HTTP clients, transport adapters, connection pools, proxy support, streaming, protocol utilities, retries, deadlines, and cancellation.

Data and serialization

Validation, schemas, parsing, serialization, conversion, structured data, and safe handling of untrusted input.

Application infrastructure

Caching, queues, concurrency, rate limiting, configuration, dependency boundaries, lifecycle management, and resilience patterns.

Security engineering

Security policy helpers, secure configuration, vulnerability intelligence integrations, dependency and supply-chain review, test fixtures, and regression tooling.

Observability and developer experience

Logging, diagnostics, metrics, tracing, typed errors, test utilities, mocks, fixtures, fuzzing helpers, CLI support, and documentation tooling.

Package names and dependency relationships remain provisional until specifications, threat models, maintenance costs, and implementation feasibility are reviewed.
