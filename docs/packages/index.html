Package map

Five areas, each with preview packages.

Reviewed November 2026 · Source repository ↗

The package map groups Ametherian into five areas. Each area now has preview packages with tests, type declarations and threat models; see Modules for details. Package APIs may still change until the first stable release.

Networking and protocols#

HTTP clients, transports, connection pools, proxies, streaming, retries, deadlines, and cancellation.

Preview packages: ametherian-http, ametherian-guard.

Data and serialization#

Validation, schemas, parsing, serialization, conversion, structured data, and safe handling of untrusted input.

Preview package: ametherian-schema.

Application infrastructure#

Caching, queues, concurrency, rate limiting, configuration, lifecycle management, and resilience.

Preview packages: ametherian-core, ametherian-cache, ametherian-resilience.

Security engineering#

Security policy helpers, secure configuration, dependency review, test fixtures, and regression tooling.

Preview package: ametherian-security.

Observability and developer experience#

Logging, diagnostics, metrics, tracing, typed errors, test utilities, fuzzing helpers, and documentation tooling.

Preview packages: ametherian-observability, ametherian-testing.
