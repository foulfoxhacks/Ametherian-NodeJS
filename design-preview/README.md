# Ametherian design prototype

This is an isolated, non-production preview on the `design-prototype` branch. Open `design-preview/index.html` through GitHub Pages preview tooling or serve the repository locally.

## Direction

- Homepage: confident Node.js-homepage-inspired story and calls to action.
- Documentation: API-reference-inspired technical layout with compact navigation and code examples.
- Brand: Ametherian remains the lead identity; amethyst is primary, Node.js green is a restrained secondary accent.
- Footer: project, developer, and policy navigation.
- Responsive: desktop, tablet, and mobile layouts with reduced-motion support.

## Important preview notes

The geometric A mark in this preview is a temporary typographic stand-in, not a replacement logo. The supplied Ametherian primary, white-on-black, and black-on-white artwork has been reviewed and should be placed into the production header/footer as the exact original files when the artwork is added to the repository. Do not redraw or alter the mark.

The Node.js name is used descriptively as a runtime/ecosystem reference. This is an independent Ametherian concept, not an official Node.js collaboration, endorsement, or partnership. The Node.js marks are not reproduced in this preview. Review the official [Node.js branding guidance](https://nodejs.org/en/about/branding/) and [OpenJS Foundation artwork and trademark guidance](https://github.com/openjs-foundation/artwork) before any use of official Node.js artwork.

All package names and API snippets are illustrative. Ametherian remains a proposal/planning-stage project; no release, audit, or implementation status is implied.
