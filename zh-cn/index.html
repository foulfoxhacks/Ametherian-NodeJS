概览

一个生态系统，可以独立采用的工具。

Node.js 开发者需要从许多包中拼装网络、校验、缓存、并发、可观测性和应用基础设施。Ametherian 研究一致的契约和清晰的包边界能在哪些地方让这些工作更易于理解和维护。

每个包都有明确的用途、有文档的行为、明确的限制，并且可以单独采用。目标不止于替换某一个 HTTP 客户端。

架构

基于 Node.js 原语构建。

Ametherian 基于运行时成熟的 API 构建，而不是另起炉灶发明一套编写 JavaScript 的方式。兼容性和性能方面的说法在发布前需要有可复现的证据。

  response.writeHead(200, { 'content-type': 'text/plain' });
  response.end('Hello from Node.js\n');

指导原则

开发准则。

这些原则是对每个包的要求；测试、威胁模型和评审会检查它们。它们适用于包边界、文档、测试和评审。

专注的包

一个包应当只承担一项易于理解的职责，并且在没有无关模块的情况下依然有用。

明确的行为

运行时要求、副作用、限制、失败模式和数据处理都应当写进文档，而不是隐藏起来。

互操作性

向成熟的库学习，在有帮助的地方与之互操作，避免不必要的重复造轮子。

证据重于说法

关于兼容性、性能、安全性和可靠性的陈述需要可复现的测试，或明确标注为目标。

安全从设计开始

威胁模型、有上限的资源和安全的默认值属于设计的一部分，而不是事后的检查清单。

经人工评审的变更

涉及安全的修复和公开说法需要由对结果负责的人评审。

常见问题

关于本项目。

关于状态、隶属关系、运行时、许可证和贡献的直接回答。

Ametherian 已经发布了吗？

尚未发布到 npm。 十个预览包 连同测试一起在仓库中公开，每个通过 CI 的构建都会以编号预览版的形式发布到 GitHub Releases。发布到 npm 需要先商定发布流程。

Ametherian 与 Node.js 或 OpenJS Foundation 有关联吗？

没有。Ametherian 是 FoulFoxHacks 的独立项目。它与 Node.js、OpenJS Foundation、Axios、Undici 或任何其他提及的项目都没有关联，未获得它们的认可，也不是它们的官方延续。Node.js 是 OpenJS Foundation 的商标。

Ametherian 可以用于生产环境吗？经过审计吗？

不可以。这些包以经过测试的预览版存在，但没有任何一个发布到 npm，也没有进行过独立的安全审计。 安全方法 和漏洞模型说明了代码如何进行威胁建模和测试；它们并不保证代码是安全的。

Ametherian 面向哪个运行时？

Node.js 22、24 和 26，各自使用最新的安全版本。这些包是带有 TypeScript 声明的 ES 模块。不支持 Node.js 20：它已于 2026 年 4 月结束生命周期。

项目将使用什么许可证？

Apache License 2.0。这是一种宽松的许可证，并明确授予专利许可。完整文本见 许可证状态 以及每个包中。

我可以参与贡献吗？

欢迎对范围、包边界、安全要求、运行时兼容性和开发体验提出早期反馈。 贡献指南 说明了相关要求。涉及安全的细节不得公开发布；请遵循 安全策略.

有发布时间表吗？

没有日期。主分支上每个通过 CI 的构建都会以编号预览版的形式发布到 GitHub Releases，并列在 更新日志中。发布到 npm 需要先商定发布流程。

Ametherian 能取代 Axios 或 Undici 吗？

不能。Ametherian 的 HTTP 客户端和 fetch() 是自有代码，已对照 Axios 和 Undici 公开的每一条安全公告进行检查。它不是直接替代品，在没有可复现证据的情况下不作任何兼容性或性能方面的声明。
