漏洞模型#

undici 和 axios 公开的每一条公告都已归类：共 111 条，其中 64 条已防范，每条都有以公告命名的回归测试； 47 条不适用，每条都记录了原因。每日工作流会在 OSV、GitHub Advisory Database 和 NIST NVD 中检查新公告。

支持的运行时#

每个版本线的最低要求是其最新的 Node.js 安全版本。当有更新的安全版本发布或某个版本线结束生命周期时，监测就会失败。

  • Node.js 22: 22.23.5 或更高版本
  • Node.js 24: 24.22.3 或更高版本
  • Node.js 26: 26.13.1 或更高版本

不支持 Node.js 20：它已于 2026 年 4 月 30 日结束生命周期。

预览意味着什么#

  • 代码、测试、类型声明和威胁模型都在仓库中公开。
  • 在商定发布流程之前，不会向 npm 发布任何内容。
  • 尚未进行独立的安全审计。

独立项目。 Ametherian 与 Node.js、OpenJS Foundation、Axios、Undici 或任何其他提及的项目都没有关联，也未获得其认可。Node.js 是 OpenJS Foundation 的商标。
